M1 → Tokenization → USDT Flow

Pull & run container: docker pull ghcr.io/quant-oss/tokenizem1:latest → docker compose up -d
POST pacs.008.001.10 XML to localhost:42881/receive — container validates and returns camt.054 credit confirmation
POST to /tokenize with intake_id — tokens minted 1:1 with intake value, status MINTED_HELD · 20% held on reserve
Submit 10% fiat release payment (USD/EUR bank or on-chain stablecoin) — POST to /release
Tokens released to circulation — USDT swap executes via QVTX settlement rail

Gates

Coherence gate: every intake is scored ≥ 0.618034 (1/φ) — a valid pacs.008 scores ~0.70 and passes automatically
Reserve gate: 20% of intake value held · Release gate: 10% fiat payment to release tokens
